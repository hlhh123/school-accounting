# 사용자에게 넘기는 확인 목록

기준일 2026-10-02. **22건**. 우선순위 ‘먼저’는 금액·가입·지급 책임이 바뀌는 항목이다. 해당 사례가 없다면 ‘해당 없음’으로 닫아도 된다. 학교별 자료가 없어서 남긴 항목과 공개 근거를 추가 확인해야 하는 항목을 구분했다.

계좌번호·비밀번호·인증서 파일·주민번호·직원 실명은 보내지 않아도 된다. 공문 제목·시행일·개인정보를 가린 해당 쪽이면 충분하다.

## 등재 전 순서

1. Q03으로 누가 급여·보험·세금을 처리하는지 확정한다.
2. 실제 사용하는 직종에 한해 Q04~Q06·Q09~Q11·Q17·Q19~Q22를 확인한다.
3. Q01·Q02·Q08로 신규자의 권한·화면·결재선 안내를 완성한다.
4. 개인정보 없는 실제 처리 화면으로 따라하기를 점검한다.
5. 답변이 없는 금액·판정은 공개 본문에서 ‘학교 담당자 확인’ 표시를 유지한다.

이 목록은 담당자가 확인해야 할 대상을 정리한 것이다. 현재 초안만으로 개별 인력의 보험 자격이나 육아휴직 정산액이 확정된 것은 아니다.
