# 슬기로운 유니생활 — 2026년형 수정 대조표

검토 기준일 **2026-10-02** / 사용자 제공 2024년 실무 메모를 바탕으로 만든 개편 초안.

**확인**은 표시한 규정 내용을 확인했다는 뜻이다. **조건부**는 대상·계약·재원에 따라 달라진다. **학교확인**은 학교 내부 자료가 필요하다. **추가확인**은 최신 조항·해석을 더 확인해야 한다. 업무 화면에서 실제 처리까지 시험했다는 뜻은 아니다. S번호는 [근거자료 목록](04-근거자료.md), Q번호는 [사용자 확인 목록](03-사용자확인필요목록.md)에 연결된다.

## 먼저 바꿀 내용

1. **학교가 전부 직접 급여를 지급한다는 전제 삭제**: 교육비특별회계 교육공무직 급여의 통합운영 확대를 반영한다. 학교회계 인력은 별도 확인한다. S04
2. **2026년 보험료율 반영**: 건강보험 7.19%, 국민연금 9.5%. 고지서와 개인별 기준액을 대조한다. S07·S08
3. **강사 보험 필요경비율 날짜 구분**: 해당 직종은 2026.7부터 19.3%. 14.9%를 연중 고정하지 않는다. 소득세 3.3%와 다른 개념이다. S13·S14
4. **육아휴직·연차 단정 삭제**: 법정/약정 육아휴직, 계약기간, 출근간주기간을 구분한다. S01·S03
5. **국세·지방세·소득자료 제출을 분리**: 같은 신고가 아니다. 소득 구분과 실제 지급일을 먼저 확정한다. S09~S12
6. **학교 내부정보 공개 제외**: 계좌·비밀번호·인증정보·실명·개별 급여 사례는 삭제하고 입력 서식으로 바꾼다.
